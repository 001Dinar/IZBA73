IZBA BAZA OTDIHA73 — сайт дома отдыха «ИЗБА»

Файлы: index.html, style.css, script.js, папка img (11 фото).

КОМПЬЮТЕР: распакуйте архив ЦЕЛИКОМ и дважды нажмите index.html (откроется в браузере).
iPad / iPhone: просмотр файла внутри приложения «Файлы» не запускает анимацию и кнопки.
Откройте сайт через интернет-адрес (GitHub Pages, бесплатно):
 1. github.com -> New repository (имя, например, izba) -> Public.
 2. Add file -> Upload files: загрузите ВСЁ содержимое архива (index.html, style.css, script.js и папку img).
 3. Settings -> Pages -> Branch: main / root -> Save.
 4. Через 1-2 минуты сайт откроется по адресу https://ВАШ-ЛОГИН.github.io/izba/

Замена фото: положите свои файлы в папку img под теми же именами (01.webp ... 11.webp).
